# Azure Lakehouse Platform

A modern cloud data engineering project demonstrating lakehouse architecture, distributed data processing, analytical modelling, data quality, and business intelligence using Azure-oriented technologies.

## Planned Architecture

```text
Source Data
    |
    v
Raw / Landing Layer
    |
    v
Bronze Layer
    |
    v
Silver Layer
    |
    v
Gold Layer
    |
    +--> SQL / dbt Analytics
    |
    +--> Power BI
```

## Planned Technology Stack

- Azure Data Lake Storage
- Azure Databricks
- PySpark
- Delta Lake
- dbt
- SQL
- Python
- pytest
- GitHub Actions
- Power BI

## Business Domain

Retail sales analytics.

The platform will process customer, product, order, and transaction data to create business-ready analytical models for reporting and decision-making.
